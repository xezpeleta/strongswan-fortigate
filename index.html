Unofficial strongSwan for FortiGate IPsec VPN — Ubuntu 26.04

Unofficial, third-party builds — not affiliated with the strongSwan project, Fortinet or Ubuntu. They patch Ubuntu 26.04's strongSwan so NetworkManager's "Certificate + EAP" method works with FortiGate IPsec dial-up VPNs using eap-cert-auth enable (FortiOS 7.4.12 / 7.6.7+ enforces the client certificate and silently drops EAP-only clients; the gateway does not implement RFC 4739). Details: strongswan#3120, source & releases.

Enable on Ubuntu 26.04:

curl -fsSL https://xezpeleta.github.io/strongswan-fortigate/add-apt-source.sh | sudo bash
sudo apt install strongswan-fortigate

The repository is signed; the InRelease GPG signature is the trust anchor. Review the (small) patches and rebuild from source if you prefer your own binaries.
